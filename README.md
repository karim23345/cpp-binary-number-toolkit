# C++ Binary Number Toolkit

A C++ project focused on working with binary numbers and exploring fundamental programming concepts.

## Features
- Binary representation of integer values.
- First complement operation.
- Binary-to-decimal conversion.
- Binary-to-octal conversion.
- Comparison of binary number objects using operator overloading.

## Concepts Practiced
- Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors
- Arrays and Loops
- Number System Conversions
- Operator Overloading

## Technologies
- C++

## Purpose
This project was developed as a practical exercise in C++ programming, binary arithmetic, and object-oriented design.
